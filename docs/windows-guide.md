# byerkn

Нативное переносимое приложение для Windows 10/11 x64 поверх [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Интерфейс на русском языке, Qt Widgets, шрифт Golos Text. Приложение из серии helloytd. Неофициальная оболочка, не продукт Flowseal.

## Запуск

Откройте `dist/byerkn/byerkn.exe`. Windows запросит права администратора: они нужны WinDivert для работы с сетевыми пакетами. Папка должна быть доступна для записи. Переносите всю папку byerkn, не только exe. Python, Qt и zapret включены; устанавливать Python или Node.js не нужно.

1. Выберите «Основной» и нажмите «Включить».
2. byerkn запустит только свой экземпляр winws и проверит HTTPS-доступ к YouTube, Discord, Google и GitHub.
3. Если другой zapret уже работает, оболочка предложит остановить его самостоятельно. Она не удаляет чужие службы, не завершает чужие процессы и не изменяет DNS, брандмауэр или антивирус.
4. Если сайт недоступен, выключите обход, выберите альтернативный профиль, включите и повторите проверку. Конкретный рабочий профиль зависит от подключения.
5. Крестик сворачивает окно в трей. Меню значка → «Выключить и выйти» останавливает собственный процесс. При аварийном завершении оболочки собственный процесс привязан к Windows Job Object и также завершается.

HTTPS-проверка подтверждает только ответ веб-сервера. Воспроизведение YouTube, загрузку с видеосерверов и голосовой UDP Discord нужно проверить в самих приложениях. byerkn не является VPN и не меняет IP-адрес.

## Настройки

- Игровой режим: расширение TCP/UDP на 1024–65535; выключен по умолчанию.
- Список IP-адресов: включает обработку официального IPSet; по умолчанию включён.
- Запуск обхода при открытии приложения: по умолчанию выключен. Автозагрузка приложения с Windows не реализована.
- Закрытие в трей: включено по запросу пользователя.
- Автоматическая проверка обновлений: при старте и каждые 6 часов.
- Автоустановка: включается отдельной настройкой; выполняется только когда собственный обход выключен. Если новая версия найдена во время работы, установка ждёт выключения.
- Пользовательские домены и исключения: домен на строку, без URL. IDN приводятся к ASCII. Исключения имеют приоритет внутри правил, использующих эти списки; специальные правила YouTube/Discord в исходных стратегиях могут работать независимо от них.

Изменение сетевых настроек доступно при выключенном обходе. После редактирования нажмите «Сохранить настройки».

## Обновления и данные

Источник обновлений закреплён за официальным GitHub репозиторием Flowseal. Программа выбирает стабильный последний релиз, скачивает ZIP по HTTPS, проверяет размер и SHA-256 из GitHub API, ограничения архива, обязательные файлы, форматы всех профилей и наличие текущего выбранного профиля. BAT-файлы не исполняются: параметры winws разбираются и передаются через список аргументов без shell.

Новые файлы сначала подготавливаются во временной папке на том же диске. При замене прежняя версия становится `data/previous-engine`; откат доступен кнопкой на странице обновлений. При отказе rename текущая папка восстанавливается. При следующем запуске приложение восстанавливает предыдущую версию, если обновление было прервано между переименованиями.

`data/settings.json` и `data/user-lists/` хранятся отдельно от движка и не заменяются обновлением. Журналы: `data/byerkn.log` (ротация), `data/engine.log` (последний запуск).

Автоматически обновляются **файлы zapret**, а не Python/Qt и не интерфейс byerkn. Для новой версии оболочки замените файлы приложения, сохранив `data`. При переносе программы сначала полностью завершите её через трей.

## Разработка и сборка

`runtime/python.exe -m byerkn` запускает исходники. Для самого обхода нужны права администратора.

`powershell -ExecutionPolicy Bypass -File build_portable.ps1` собирает `dist/byerkn` и ZIP из локальных `runtime` и `bundle`. Если в существующей установке есть `data`, сборщик оставляет эту папку приложения целиком на месте и создаёт обновлённый ZIP рядом. Старый параметр `-KeepExistingData` по-прежнему принимается. Среда — официальный CPython 3.13.17 embedded x64 и Windows Widgets из PySide6-Essentials и shiboken6 6.12.0.

С чистого репозитория сначала выполните `powershell -ExecutionPolicy Bypass -File bootstrap.ps1`: подготовка Python и Qt с проверкой архивов по SHA-256, загрузка версии zapret из `upstream-release.json`. Новые зависимости проверяются во временной папке перед заменой рабочих. Затем сборка.

Проверки:

```powershell
.\runtime\python.exe -m unittest discover -s tests -p 'test_*.py' -v
.\runtime\python.exe tests\validate_engine.py
.\runtime\python.exe tests\capture_ui.py
.\runtime\python.exe tests\online_checks.py
```

`validate_engine.py` запускает только `winws --dry-run` без драйвера; требует обычного Windows окружения, Cygwin несовместим с ограниченным AppContainer. `capture_ui.py` использует временные изолированные настройки, не включает обход и не делает запросы. `online_checks.py` делает только HTTP-запросы и проверяет список процессов, без изменения сети.

## Сторонние компоненты

См. `THIRD_PARTY.md` и папку `licenses`, а также лицензии runtime и PySide6/shiboken6. Код оболочки поставляется с исходниками. Неподписанный локальный exe может показывать «Неизвестный издатель» в запросе Windows; подпись издателя не настроена.
