byerkn — portable-версия для Windows 10/11 x64

Запуск: byerkn.exe. Windows запросит права администратора — они нужны драйверу WinDivert.
Устанавливать Python, Qt или zapret отдельно не нужно.

Переносите всю папку целиком:
  byerkn.exe  — запуск программы
  byerkn\     — исходный код интерфейса
  runtime\    — собственный Python и Qt
  bundle\     — начальная проверенная версия zapret
  assets\     — шрифт и значок
  licenses\   — лицензии сторонних компонентов
  data\       — настройки, текущий движок и журналы; появится при первом запуске

Крестик сворачивает программу в трей. Чтобы остановить обход и полностью выйти,
нажмите правой кнопкой по значку byerkn рядом с часами → «Выключить и выйти».

Обновления zapret загружаются только из официального репозитория Flowseal и
проверяются по SHA-256. Настройки и пользовательские домены хранятся отдельно.

byerkn — независимая оболочка, не официальный продукт Flowseal.
Подробности и лицензии: README.md и THIRD_PARTY.md.
